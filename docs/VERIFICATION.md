# Проверка MVP

Проверено локально 4 октября 2026 года на macOS, Node.js 22.22.3 и Docker Desktop. Эти результаты относятся к созданной версии MVP.

| Проверка                    | Результат                                                     |
| --------------------------- | ------------------------------------------------------------- |
| `pnpm lint`                 | Успешно, без предупреждений                                   |
| `pnpm typecheck`            | Успешно, strict TypeScript                                    |
| `pnpm format:check`         | Успешно                                                       |
| `pnpm test`                 | 26 тестов прошли                                              |
| `pnpm test:integration`     | 13 тестов прошли на отдельной PostgreSQL-базе `fieldops_test` |
| `pnpm exec prisma validate` | Схема корректна                                               |
| `pnpm db:migrate`           | Начальная миграция применена                                  |
| `pnpm db:seed`              | Демоданные созданы, повторный запуск сохраняет записи         |
| `pnpm build`                | Production-сборка прошла                                      |
| `docker compose config -q`  | Конфигурация корректна                                        |
| `docker compose build`      | Образы `app` и `init` собраны                                 |
| Docker `init`               | Миграции и seed выполнены, код выхода 0                       |
| Docker `db`                 | PostgreSQL 17 запущен и healthy                               |
| Docker `app`                | Standalone-приложение работает на `127.0.0.1:3000`            |
| `pnpm test:smoke`           | Прошёл на локальной Node-сборке и затем на Docker-приложении  |

Интеграционные тесты проверяют создание и назначение заявки, ограничения ролей, связь устройства с объектом, единственный активный выезд, поездку и прибытие, принадлежность шагов шаблону, завершение диагностики, запрет её дальнейшего редактирования, откат некорректного решения, создание истории ремонта и закрытие заявки.

HTTP-проверка включает анонимный доступ, вход Auth.js, 15 страниц, фильтр инженера, недоступный чужой инцидент, запрет изменений для наблюдателя, проверку `Origin` и поиск по IP. Бизнес-сценарий проверяется сервисами на PostgreSQL, а не полностью автоматизированными кликами по интерфейсу.

В браузере проверены вход демо-инженера, dashboard, загрузка MapLibre и карточка инцидента. На ширинах 1280 и 390 px карточка не создаёт горизонтального переполнения страницы. Снимки находятся в `docs/screenshots/`.

После повторного seed в основной демо-базе осталось 5 пользователей, 16 объектов, 144 устройства, 20 инцидентов и 6 выездов. Тесты использовали отдельную базу и удалили только свои временные записи.

Не проверялись публичное развёртывание, реальные интеграции с оборудованием и полный набор браузеров/мобильных устройств. Мониторинг и оповещения используют вымышленные состояния; симулятор и AI-провайдер входят в roadmap.
